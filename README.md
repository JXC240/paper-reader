**让 AI 陪你读，把理解留给自己。**

一个本地运行的 PDF 阅读伴侣。先读英文原文，随手标出卡点，再带着完整句子和上下文找 AI；把值得积累的内容留给下一次阅读。

**自主阅读 → 随手标注 → AI 伴读 → 回到原文 → 积累与复习**

![用自制英文示例展示论文、标注和笔记](docs/images/reader-v0.4.png)

## 为什么做这个工具

我想在 GPT 聊天旁边自己读英文论文，但内置 PDF 查看器没有提供我需要的完整标注体验。遇到生词、长难句或陌生方法时，每次切换窗口、复制文字、补上页码，很容易打断阅读；逐处写“没看懂”，又让简单的标记变得繁琐。

Paper Reader 来自这个需要：先自己尝试，读过一小段再带着卡点讨论，最后回到英文原文读一次。我们希望这种持续练习，能帮助读者逐渐抓住句子结构、学术表达和作者的论证。**培养直接阅读英文论文的能力，是长期目标；工具使用和笔记数量不是学习效果的证明。**

## 阅读时，它能帮你做什么

| 你想做的事 | 对应功能 |
| --- | --- |
| 顺手留下卡点 | 连续标记或先选后标；七色高亮、下划线、删除线 |
| 随时继续阅读 | 持久保存标注、笔记、书签、页码、缩放与页内位置；笔记草稿保护 |
| 找到并回到原文 | 全文搜索、PDF 内置目录、页面书签、键盘翻页 |
| 带着上下文问 AI | 原文、页码、附近文本、复制阅读卡点、固定论文链接 |
| 带走自己的积累 | Markdown、标准批注 PDF 副本、完整阅读库备份与独立恢复 |
| 日常打开就读 | 本机网页；macOS 可选登录后台服务与退出后自动重启 |

## 三步开始

需要 **Python 3.10+**。首次准备环境需要联网；日常阅读、标注与保存可以离线。使用阅读器不需要 Node.js 或模型 API key。

1. **下载并启动。** [下载源码 ZIP](https://github.com/JXC240/paper-reader/archive/refs/heads/main.zip)，解压到独立目录。macOS 双击 `启动阅读器.command`，或在项目目录执行：

   ```sh
   ./start.sh
   ```

2. **打开示例。** 在同一台电脑访问 [本机阅读器](http://127.0.0.1:8877/)，点击“试试示例 PDF”，尝试选择一句话并标注。默认前台运行需要保留启动窗口；停止时按 Control+C。

3. **打开自己的论文。** 在普通浏览器或支持本机内置浏览器的桌面聊天应用中打开同一地址。读过一段后，复制阅读卡点到聊天。有本机文件权限的助手也可读取论文专属记录。

打开多个聊天读不同论文时，使用“复制论文链接”，让每个聊天固定打开自己的论文。链接只能在运行该阅读库的本机使用，不能让其他电脑访问你的论文。

详细步骤：[使用、后台服务与备份](docs/USAGE.md) · [安装／并排打开／AI 伴读／Obsidian／每周复习提示词](docs/WORKFLOWS.md)

## 先读，再与 AI 讨论

高亮可以表示没读懂、重要方法或值得回看的结论，不会自动变成生词。你可以先尝试说出句子大意，再请 AI 结合完整句子解释；讨论后回到原文，用自己的话复述。

如果希望长期积累英语，可以授权具有本机文件权限的助手，将确认要收录的词汇、搭配和长难句写入 Obsidian，每周先回忆、再核对。上面的提示词指南提供完整模板。**AI 讲解、Obsidian 写入和定时复习由你选择的助手完成，不是阅读器内置的自动功能。**

## 数据留在哪里

PDF 与已保存标注保存在项目的 `data/`，原 PDF 不被覆盖。未保存笔记草稿还会尝试暂存于当前浏览器；只有点击“保存笔记”后才进入阅读库、导出与备份。

“备份阅读库”下载包含论文和记录的 ZIP；恢复工具验证文件后写入一个新目录。换电脑或升级前，建议先备份并验证恢复。步骤见[备份与升级指南](docs/USAGE.md#备份恢复与升级)。

Paper Reader 不主动把论文上传到模型或云端。复制到 AI 或授权助手读取的内容，会进入相应应用的工作流。源码 Git 记录不包含你的私人阅读数据；备份文件也不应上传公开仓库。

## 支持与边界

- **macOS** 是主要实测环境；Linux 提供启动脚本与自动化检查，Windows 尚无经过验证的一键入口。
- 当前界面主要为中文；英文使用指南与提示词已提供。
- 逐页阅读；尚无连续滚动、扫描件 OCR、跨页一次选文、图表框选或多步撤销／重做。
- 文本提取受双栏、连字符、公式和 PDF 文本层影响，科学结论与引文需要回原文核对。
- 侧栏管理本工具新增标注；原 PDF 已有批注在导出时保留，尚不自动导入侧栏。
- `127.0.0.1` 是当前设备，不是公网网址；并排打开与本机文件权限取决于聊天客户端。
