## 安装与启动

需要 Python 3.10+。下载源码 ZIP 后解压到独立目录，或使用 Git：

```sh
git clone https://github.com/JXC240/paper-reader.git
cd paper-reader
./start.sh
```

首次启动会创建项目自己的 `.venv/`，安装固定版本的 pypdf，并下载经过校验的 PDF.js 资源。网络只用于首次准备和依赖修复；不需要修改全局 Python，不需要 Node.js 或模型 API key。

macOS 可双击 `启动阅读器.command`。在运行服务的同一台电脑打开 http://127.0.0.1:8877/，首次先试自制示例。前台模式保留启动窗口，Control+C 停止。

- 找不到 Python：先安装 Python 3.10+，重开终端确认 `python3 --version`。
- 环境不完整或下载失败：按启动提示处理后重新运行 `./start.sh --prepare-only`；不要关闭证书验证。
- 端口已占用：先打开阅读器地址确认是否已运行；需要独立实例时使用 `./start.sh --port 8878 --data-dir /绝对路径/独立阅读库`。
- 连接被拒绝：检查前台窗口或后台服务状态；浏览器页面本身不会启动 Python 服务。
- 从 ZIP 下载后提示权限问题：在项目目录执行 `sh start.sh`。macOS 的安全提示需要根据来源核对后按系统方式处理。

## 与聊天并排阅读

在支持本机内置浏览器的桌面客户端中打开本机地址；普通浏览器也能使用。客户端能力、系统与权限会影响并排展示和本机文件访问。

使用“复制论文链接”固定当前论文，链接包含 `?doc=<论文ID>`。把它交给另一个聊天或在新标签打开，同一阅读库会打开指定论文。指定论文不存在时会提示错误，不静默改读其他文档。链接没有携带 PDF；其他电脑的 `127.0.0.1` 也不是你的电脑。

“复制阅读卡点”包含论文标识、页码、原文、附近文本和已保存笔记；有文件权限的助手可以读取：

```text
<项目目录>/data/documents/<论文ID>/record.json
<项目目录>/data/documents/<论文ID>/reading.md
```

若使用 `--data-dir`，以上 `data/` 应换为实际目录。全局 `current-reading.json` 仍用于兼容早期工作流，但多聊天时以论文专属路径和名称为准。助手没有本机权限时，复制或导出内容即可。

## 标注、笔记与快捷键

- 默认连续标记：选中文字便保存标注。关闭后可先选文，再决定标记或复制。
- 七色 × 高亮／下划线／删除线；卡片可以换样式、颜色、删除或收为生词。
- “生词”是主动分类，不把所有高亮自动认作词汇。
- 笔记输入后显示草稿状态，翻页、缩放、筛选时保留；同一浏览器允许本地存储时，刷新后可恢复。点击“保存笔记”后才写入本机阅读库。草稿不属于 PDF、Markdown 或阅读库备份；浏览器清理数据也可能删除草稿。
- 快捷键和翻页入口见页面的“使用说明”。在输入框中编辑时，阅读快捷键不抢占正常输入。
- 缩放输入 25%—400%，允许小数；⌘／Ctrl +、−、0 分别放大、缩小、适合宽度。
- ⌘／Ctrl F 打开全文查找；Enter／Shift Enter 切换结果。搜索橙框只是临时提示。
- Esc 或点击空白取消选文；滚动时浮动选文菜单会收起。
- 目录来自 PDF 自带目录；无目录会提示。书签可以按页收藏并命名。
- Markdown 便于带入笔记；批注 PDF 是保留原件的独立副本。

## macOS 可选后台服务

想日常使用时不保留终端窗口：

1. 等待所有标注与笔记保存；如有前台服务，在其窗口按 Control+C。
2. 双击 `安装后台服务.command`，按提示准备环境并安装当前用户的后台项。
3. 以后直接打开本机地址；`启动阅读器.command` 会复用或重新启用已安装的后台项。

| 操作 | 入口 |
| --- | --- |
| 安装登录后台服务 | `安装后台服务.command` |
| 停止并禁用自启 | `停止后台服务.command` |
| 再启用 | `启动阅读器.command` |
| 卸载后台项，保留数据 | `卸载后台服务.command` |

无需管理员权限；仅监听本机。配置为 `~/Library/LaunchAgents/local.paper-reader.plist`，日志为 `~/Library/Logs/PaperReader/`。移动项目目录前先卸载后台项，移动后重新安装。后台项不改变电源设置；真实隔夜休眠、重新登录和系统重启仍需使用验证，自动重启不能替代备份。

## 备份恢复与升级

### 创建并核对备份

先点“保存笔记”，等待“已保存到本机”，再点“备份阅读库”下载 ZIP。归档包含导入 PDF、已保存标注／笔记／书签／位置以及校验清单；不包含浏览器未保存草稿、运行环境或可重新生成的导出文件。

备份含私人论文和阅读记录，保存到自己的安全目录，别放入公开 GitHub。可以同时复制整个 `data/` 作为离线备份；复制前停止服务更容易得到一致副本。

内置备份支持解压后最多 1 GiB、3,000 篇论文；超过限制会明确停止，请使用整个数据目录的离线副本。Windows 上的恢复流程尚未验证。

### 恢复到独立目录

恢复工具校验归档路径、清单、文件哈希与记录，写入一个**尚不存在的新目录**，不会合并覆盖正在使用的阅读库：

```sh
.venv/bin/python scripts/library_backup.py restore /绝对路径/paper-reader-backup.zip --to /绝对路径/reader-restored
./start.sh --port 8878 --data-dir /绝对路径/reader-restored
```

打开 http://127.0.0.1:8878/，核对论文数量、几条标注、笔记、书签和导出结果。确认后再决定是否用此恢复库替代日常库；换库前停止相关服务并保留旧库。默认 macOS 后台配置仍绑定项目内的 `data/`，不会自动改用恢复目录。

单份记录损坏时，阅读器会提示并继续列出可读取的论文；损坏记录仍保留。完整备份遇到无法验证的记录会报错，避免将缺文档的归档称为完整备份。优先保留原库并从已验证备份恢复。

### 安全升级

1. 保存全部笔记并备份，确认备份可恢复。
2. 停止服务。后台模式用 `停止后台服务.command`，前台用 Control+C。
3. Git 安装：查看本地改动，确认要更新的分支后执行 `git pull --ff-only`。ZIP 安装：将新版解压到新目录，保留旧目录与数据；移动后台项目需先卸载旧后台项。
4. **必须运行 `./start.sh --prepare-only`**，以准备新版依赖。后台模式直接双击启动可能复用旧环境，不能替代这一步。
5. 启动新版并刷新阅读页面，核对已保存论文和标注。后台模式双击 `启动阅读器.command`；新目录可按需重新安装后台项。

升级源码不会自动回滚或迁移私人记录。回退旧代码时用独立目录与备份副本验证，勿直接覆盖日常阅读库。

## 数据目录

```text
data/
  documents/<PDF的SHA-256>/
    original.pdf
    record.json
    reading.md
  active.json
  current-reading.json
  current-reading.md
  exports/
```

同一 PDF 改名导入复用记录；内容改变会识别为另一份论文。Git 忽略阅读数据，但公开分享归档前仍需检查内容。
