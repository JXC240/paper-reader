打开 PDF → 选中文字标黄 → 回到聊天说“讲一下刚标黄的句子”。高亮会保存在本机。助手可读取项目下的 data/current-reading.json，也可以使用“复制阅读卡点”。

高亮默认表示整句理解卡点；只有点击“收为生词”才会进入导出笔记的生词分类。原 PDF 已有批注会显示并保留，列表记录本工具新增的高亮。导出的 Markdown 可在 Obsidian 中打开。扫描页暂不支持自动识字，双栏和公式请结合原文核对。

缩放框可输入 25%—400% 的比例，按回车确认；也可用 − / + 按钮。⌘ / Ctrl 加 + 或 − 缩放，⌘ / Ctrl 加 0 适合宽度（需阅读页面获得焦点）。取消选文、点空白、滚动或按 Esc 可收起选文菜单。

先选“高亮／下划线／删除线”和颜色，再拖选文字。连续标记开启时自动保存，选文模式则需点击“标记这段”。已有标注可在右侧卡片中换颜色或样式；删除线只画线，不会删除PDF原文。

“搜索”可查找整篇论文的文字（⌘ / Ctrl F），点击结果回到原文；搜索框内 Enter / Shift Enter 切换结果。搜索框只是临时提示，不会新增标注。“导航”提供 PDF 自带目录与页面书签；☆ 可收藏当前页。页码、比例和页内阅读位置会保存在本机。
